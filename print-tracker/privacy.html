Privacy policy of the Print Tracker browser extension

Last updated: 2026-10-21

The Print Tracker extension connects the browser to a Print Tracker server that the user runs themselves. It has no server, account or analytics of its own.

What the extension stores

The address of the user's Print Tracker server and the API token the user enters in the options. Both stay in the local storage of the browser (chrome.storage.local) and are not synced.

What the extension sends, and where

Only to the Print Tracker server the user entered, and only on pages of MakerWorld, Printables and Thingiverse:

  • the address of the current model page, to ask whether the model is in the library;
  • the address of the page and the tags the user typed, when the user chooses to save the model;
  • the API token, to authenticate these requests.

The extension reads no other pages, no browsing history and no personal data. It sends nothing to the developer or to any third party, and it loads no code from the network.

What is not done

  • No data is sold or transferred to third parties.
  • No data is used for purposes unrelated to saving models to the user's server.
  • No data is used to determine creditworthiness or for lending.

Removing the data

Removing the extension deletes the stored address and token. What was saved to the Print Tracker server is under the control of whoever runs that server.
